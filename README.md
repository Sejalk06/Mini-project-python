# MediVision AI — Frontend

A responsive, static educational human anatomy learning website.

## Publish quickly with GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root (not inside an extra nested folder).
4. Commit the files.
5. Open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown there.

## Features
- Responsive dashboard and navigation
- Anatomy overview with clickable heart, lungs, and brain hotspots
- Body-system learning cards and organ profiles
- Five-question interactive quiz with score feedback
- No build step or API key required

## Important limitations
This is a frontend-only educational prototype. It does not include an AI backend, medical diagnosis, or a fully rotatable 3D anatomical model. The anatomy overview attempts to load an external Wikimedia Commons reference image; an illustrative fallback appears if that image is unavailable. The website uses an internet connection for Google Fonts and the external image. All content is for education only and is not medical advice.
